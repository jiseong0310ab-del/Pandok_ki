# SAYNUE — 2026-11 경쟁 기능 검수 & 개선 백로그
2026-11-17 | 비교 기준: 경쟁사 공개 소개·스토어 기능 설명, SAYNUE GitHub 소스

## 결론
세이뉴는 기본 AI 요약/증거/반대 해석/다음 행동/답장 한 개를 제공하지만, 경쟁 앱 대비 **입력 범위(1장 캡처), 답장 개인화(기존 없었음), 지속적 코칭, 직접 증거 표기, 개인화 기록**이 약하다. 반면 다국어(한국어·일본어·영어·중국어 간체/번체) 지원과 답장하지 않는 조언을 허용하는 신중함이 강점.
**경쟁사의 상세 기능은 공개 설명 기준**이며 직접 유료 기능을 구매해 테스트하지 않았다.

## 우선순위 및 의존성
### P0 — 실제 판매/대규모 홍보 전에 필수
1. **Paddle 상품 수용 가능성 확인**. 공식 Paddle AUP에 'dating services/applications' 및 'automated decision-making or categorization of people' 금지 규정이 존재. SAYNUE는 실제 사람들이 만나도록 연결하는 앱은 아니지만 관계/호감 점수 기능이 있는 만큼 **사업 내용, 샘플 출력, 판매 예정 유료 기능을 사실대로 제시하고 Paddle의 명시적 서면 판단을 받기 전까지 실제 결제 활성화 금지**. Sandbox 상품 생성/테스트는 실판매 승인 아님. 정책 위반 회피를 위해 허위 카테고리 변경 금지.
2. **Gemini 데이터 처리**. Google Gemini API 무료/미결제 할당량은 제출된 내용이 제품 개선에 활용될 수 있고 검토자가 읽을 수 있다고 규정. 사용자 대화는 민감할 수 있어 무료 할당량 실서비스 사용은 위험. 유료 Billing 연동, 적법한 처리 고지, 보관/삭제/국외 이전, 입력 전 마스킹 검토.
3. **실제 과금·권한 검증**. 인증/DB·Paddle raw-body 서명 웹훅·중복 이벤트 처리·취소/환불/결제 실패 후 권한 조정, 결제 테스트. 현재는 절대 Plus 접근을 허용하지 않는 분리 구조 유지.
4. **API 비용·오남용 통제**. 현재 Upstash 없을 때 인스턴스 메모리 6회/시 제한으로 분산 환경 전체의 예산 통제가 불가. Redis 일별 쿼터, 월 원가 한도, 알림. 구독 '무제한' 표현 금지.

### P1 — 고객이 차이를 즉시 느낄 기능
1. **답장 말투 선택 [구현]**: '자연스러움/다정함/명확함/가벼움' 중 하나를 자유롭게 선택, 무료는 1안. 사용 안 하면 기본 natural. 실제 거절에서는 톤과 관계없이 경계 존중.
2. **근거 카드 구조화**: 캡처/텍스트에서 실제 문장 단위의 '관찰된 사실 / 가능한 해석 / 다른 설명'을 2~3개 카드로 표시. 타임스탬프/감정/이모지는 보이는 경우만. 사람 호감도 확률로 오해하지 않게 강화.
3. **캡처 개인정보 가리기**: iPhone Safari에서 사진 업로드 후 손가락으로 이름/프로필 사진/전화번호 등을 가리는 터치 편집 UI. 편집한 이미지만 분석 서버에 전송, 원본 미저장. 효과를 잘 검증하기 전까지 '안전한 자동 익명화'라는 문구 사용 금지.
4. **여러 장 캡처**: 최소 2~3장 순서 지정·삭제·합계 용량 제한, 모델 비용 측정. 서로 다른 사람이 보낸 말/순서 확인 UI.
5. **빈약한 입력 방지**: 한쪽 메시지만 보이는 대화에 낮은 근거 수준 및 사유 표시; 실제로 없는 답장 속도/심리 분석 금지.
6. **후속 답장 리라이팅**: 무료 1회 문장 다듬기 vs Plus 3개 스타일 비교(원문은 가능하면 서버에 저장하지 않고 처리). API 호출 제한·권한 검증 필요.

### P2 — 반복 사용 및 광고/Plus 확장
1. **대화 내보내기 파일 가져오기** (LINE/KakaoTalk/WhatsApp 텍스트). 파일 형식별 파서·권한·참여자 구분, 대화 전체 업로드 전 요약/필터링 UI 검토.
2. **기기 내 비저장 또는 암호화 기록 선택**: 기본은 미저장, 사용자가 선택할 때만 기기 내 결과 저장; 한 번 클릭 삭제. 공개 사이트/공유 단말기 안전성 검토.
3. **사용자 질문형 코치**: 현재 분석에 근거한 후속 질문으로 가치 확장하되 개인정보/원가/유료 권한 체계 선행.
4. **광고용 공개 교육 콘텐츠**: 사적인 대화 분석 화면에 AdSense 광고를 두지 말고 가이드 콘텐츠를 먼저 확장. AdSense 심사와 지역별 CMP 정책 준수.

## Plus 가치를 분명하게 하는 상품 설계 제안
Free: 대화 1건 분석 + 근거/다른 설명/추천 행동 + 선택한 톤의 답장 1안.
Plus (출시 전 미구현): 한 대화에 대한 **서로 다른 3안(다정·담백·명확) 및 왜 그 말이 맞는지 비교**, 반복 채팅의 변화 추적, 상황별 다음 행동, 복사/수정의 편리함, 광고 없는 공개 가이드 경험.
조건: 3안은 같은 문장 말끝만 바꾸는 가짜 차별화가 아니라 전략상 의미 있게 달라야 함. 선택권을 제공하되 상대의 명시적 거절 상황에서는 모든 안이 비연락/경계 존중을 반영해야 함.
가격·횟수: 실제 원가, Paddle 승인 가능성과 이용자 실험을 거쳐 결정. 현재 Plus 구매/권한은 비활성.

## 이번 패치 및 남은 검증
- [x] 답장 톤 필드 검증: natural / warm / direct / light. 허용되지 않은 문자열은 400 거부, 기존 클라이언트는 natural 기본.
- [x] 5개 언어 입력 선택과 서버 프롬프트 연결, 기존 거절 상황 보호 정책 강화.
- [x] 무료/Plus 소개의 무료 기능 설명을 톤 선택 기능과 일치시킴.
- [ ] 실제 iPhone Safari UI 작동·말투 반영 실호출 테스트. UI 배포와 API 문법 검사가 성공하더라도 품질 보장은 아님.
- [ ] 우선순위 P0 및 P1 미구현 항목은 아직 작업할 계획. 서류·결제사/비자 허가를 받은 것으로 간주하지 않음.

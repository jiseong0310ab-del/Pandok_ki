# SAYNUE — 가치 창출 및 수익화 실험 계획
작성: 2026-11-17 | 상태: 실행 가설 (확정 가격·검증 매출 아님)

## 한 문장 포지셔닝
대화의 맥락을 근거와 함께 이해하고 **내 말투로 다음 한마디를 결정하도록 돕는** 다국어 AI 커뮤니케이션 코치.
"속마음 확률 측정", "상대 감정 확정" 또는 "성공률 보장"은 하지 않는다.

## 가장 중요한 문제
현재 고객의 진짜 질문은 "상대방의 마음을 정확히 알 수 있나?"가 아니라
"저 말의 의미를 어떻게 해석하고, 지금 나는 어떻게 반응해야 할까?"이다.
점수만 보여주면 한 번 보고 끝날 수 있으므로, 세이뉴는 분석 → 다른 해석 → 실행 가능한 답장 → 이유까지 연결한다.

## 타깃 고객과 우선순위
1. 1차: 한국·일본에서 LINE/카카오톡 대화의 미묘한 표현을 고민하는 사용자.
2. 2차: 영어권의 WhatsApp/iMessage/Instagram 대화 사용자.
3. 3차: 친구·직장 관계의 오해/경계 설정. 연애만을 브랜드 중심에 두지 않는다.

## 무료와 유료의 경계
| 구분 | 실제 고객 가치 | 출시 상태 |
|---|---|---|
| 무료: 대화 맥락 해설 | 근거, 반례, 친밀감 신호(확률 아님), 상호성, 근거 충분도 | 제공 중 |
| 무료: 목적 기반 해석 | '의미 이해/답장/관계 회복/경계 표현' 목표별 요약 | 제공 중 |
| 무료: 즉시 활용 가능한 답장 예시 | 실제 대화에 맞는 **한 개**의 수정 가능한 초안과 이유 | 제공 중 |
| 유료: 상황별 3안 | 다정/담백/분명한 표현 + 장단점과 주의점 | 계획, 미출시 |
| 유료: 대화의 분기점 | "상대가 A라고 답하면..." 같은 현실적인 다음 대화 선택지 | 계획, 미출시 |
| 유료: 심층 검토 | 여러 메시지 패턴, 오해 방지, 경계와 존중 중심 전략 | 계획, 미출시 |

유료 내용은 서버에서 결제 권한 확인 후 생성·전송해야 한다. CSS 잠금/공용 코드 방식 금지.
결제 웹훅, 환불, 결제 중복 방지, 글로벌 통화 및 소비자법 준수가 완료될 때까지 CTA는 비활성화한다.

## 가격은 가설로만 테스트
- 건별 심층 분석 선호도 검증: 한국 2,900원 vs 4,900원, 일본 ¥390 vs ¥590, 영어권 $2.99 vs $4.99 (실제 표시/판매 시작하지 않음)
- 월 구독은 "1회성 고민"의 특성상 즉시 강제하지 않는다. 반복 사용 의사가 확인되면 월간 크레딧 상품 A/B 검토
- 가격은 타사의 실제 결제 가격, 목표 사용량, 환불·결제 수수료, 현지 세금/환율을 반영해 조정
- 구매 의향 수집을 할 경우 "결제 불가, 준비 중"을 분명히 안내하고 연락처를 무단 수집하지 않는다

## 핵심 KPI (현재 계측되지 않음)
- **North Star**: 분석 성공 후 답장 초안을 복사하거나 스스로 수정해서 활용했다고 응답한 비율
- 분석 완주율(입력→결과), 503/429 비율, 목표별 초안 만족도, 재방문, 유료 심층 분석 구매 의향
- 초기 목표는 실험 가설: 성공률 95%+, '도움이 되었다' 60%+, 답장 복사 20%+; 실제 사용자 테스트로 수정
- 개인정보를 보호한 집계만 사용. 대화 원문, 상대 연락처, 자유입력, raw IP를 분석 데이터로 저장하지 않는다.
- 별도 분석/마케팅 SDK 도입 시 동의, 데이터 목적, 보관 기간 등을 먼저 정책에 공개한다.

## 비용 가설 및 운영
Gemini 3.5 Flash-Lite 정가(2026-11-17 확인): 유료 Standard 입력 $0.30 / 백만 토큰, 출력 $2.50 / 백만 토큰.
**예시 계산**: 2,000 입력 토큰, 1,000 출력 토큰 기준 $0.0031/성공 요청 (= $0.0006+$0.0025).
이는 API 토큰 비용만 포함한다. 긴 대화, 스크린샷, 생각 토큰, 재시도, Vercel, DB, 결제 수수료, 세금, 지원 비용은 별도.
실제 운영비는 Google usage metadata와 익명 집계 기준으로 측정하고 월간 한도를 설정한다.
공식: https://ai.google.dev/gemini-api/docs/pricing

## 개인정보 및 신뢰 우선 체크리스트
- [ ] 실제 사용자가 대화를 맡기기 전 **유료 Gemini API의 처리 조건** 검토 및 적용 (무료 API는 제품 개선에 데이터 사용 가능)
- [ ] 법정 개인정보처리방침/이용약관/미성년자 접근 및 문의·삭제 요청 채널 마련
- [ ] 이미지 얼굴·이름 자동 삭제를 보장하지 않는다. 사용자가 직접 가려야 한다.
- [ ] 공용 베타 이전 Upstash 등 분산 제한과 봇 탐지/월간 예산 상한 설정
- [ ] 중요: 점수는 감정의 사실이나 확률이 아닌 '대화 신호 요약'; 상대에게 조종적 메시지 작성을 돕지 않는다
- [ ] 출시 국가별 Google 서비스 가용성, 상표·도메인, 결제·반품 규정 검토
- [ ] 개인정보 없는 테스트 대화로 한국어/일본어/영어·스크린샷 정확도 평가

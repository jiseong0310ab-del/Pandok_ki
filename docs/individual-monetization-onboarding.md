# SAYNUE — 개인 개발자 글로벌 수익화 개설·구현 계획
조사 기준: 2026-11-17. 비즈니스/세금/결제 심사에 대한 법률 확답이 아닌 운영 계획. 실제 판매, 광고, 계정 개설은 아직 시작하지 않음.

## 판단의 출발점
- 현재: 사업자 등록 없는 개인, iPhone 중심 개발, 기존 GitHub 저장소 Pandok_ki, Vercel https://saynue.vercel.app.
- 판매자 등록 국가, 세무 거주국, 정산 계좌의 국가는 미확정. 이 셋을 확인하기 전에는 결제사 확정·라이브 결제 금지.
- 회사/개인사업자 등록 서류가 없어도 Paddle은 개인/sole trader 신청이 가능하며 법인용 사업체 검증을 면제한다. 다만 본인 인증, 사이트 심사, 계정 승인은 반드시 필요.
- Stripe 일본은 개업신고(開業届)를 제출하지 않아도 개인사업자 등록 가능. 그러나 비사업 일반 개인은 일본 Stripe 서비스 약관에서 사전 승인 요구. 일본 개인사업자 판매로 실질 활동하고 정산 계좌와 본인 확인 준비 필요.
- Stripe 결제 판매자 계정 개설 지원 국가 목록에 일본은 있으나 한국은 현재 직접 등록 가능한 국가로 확인되지 않음. 한국 소비자가 한국 결제수단으로 구매 가능한 것과 한국에 Stripe 셀러 계정을 여는 것은 다르다.
- 구매자의 간접세를 처리하는 Merchant of Record인 Paddle을 우선 검토하되 개인소득세·거주국 신고/인허가 의무까지 면제되는 것은 아님.

## 바로 신청 가능한 계정 — 사용자가 직접 수행
1. Paddle: https://www.paddle.com/ → 계정 생성, 개인/sole trader 선택. 합법적 실제 거주국·주소·생년월일·신분증·정산계좌 입력. saynue.vercel.app을 판매 도메인으로 제출해 심사. 계정 승인을 보장하지 않음.
2. Stripe 일본(일본에서 실질 운영·정산 가능한 경우만): https://stripe.com/jp → 個人事業主로 가입. 일본 거주지/대표자 실명/일본 은행계좌/특정상거래법 표시 준비. 다른 국가 거주자가 일본 계정만 임의로 만드는 것은 불가.
3. Google AdSense: https://adsense.google.com/start/ → 개인(Individual) 계정 신청 가능. 본인확인 및 수신 가능한 우편주소 필요. 기존 개인/조직 계정 유형을 간단히 변환할 수 없으니 첫 가입 시 주의.

신분증, 은행 계좌번호, API 비밀키는 ChatGPT/GitHub/메신저에 붙여넣지 않고 결제사 보안 화면에서만 입력.

## 실제 결제사 필수 심사 정보
Paddle 사이트 심사: 웹사이트 HTTPS, 명확한 제품 설명, 실제 판매 가격 및 포함 기능, 개인정보처리방침, 이용약관, 환불 정책, 판매자 신원. 현 plans.html은 예정 상품 소개 페이지이며 실제 판매 가격·법적 사업자 신원·정책은 아직 없어 정식 심사 완료 상태가 아님.
Stripe 일본은 특정상거래법(特定商取引法) 표기가 추가 요구. 운영자의 실명/주소/연락처가 요구될 수 있어 개인정보 노출·공개 요건을 전문적으로 확인. 허위 정보 금지.
Paddle 수수료: 기본 5% + $0.50/건. $10 미만 상품은 별도 요율 상담. 판매자 정산 최소 $100, 직접 정산 통화 목록에 JPY/KRW가 없어 해외 송금/환전 비용을 확인할 것.
일본 Stripe: 기본 카드 처리 3.6%; 구독용 Stripe Billing 별도 0.7%. 국제·환전·추가 서비스 비용 및 세금 별도. 일본 국내 은행 계좌가 실질적으로 있어야 함.
Paddle/Stripe 모두 개인 자격 수용 ≠ 심사/정산/세금 의무가 자동 보장되는 것은 아님.

## 정식 광고 도입 전 단계
- AdSense 개인 계정 심사: 광고 수익을 받을 법적 개인 정보, 웹사이트 도메인 소유권, 독창적인 실제 가이드 콘텐츠, 명확한 탐색, 사이트 완성도, 연락처·필수 법정 정책.
- Google AdSense 정책상 사적 대화가 주 콘텐츠인 화면에 Google 광고 금지. 메인 입력·결과 화면에는 광고 코드를 넣지 않음. guide.html 같은 실제 읽을 가치가 있는 공개 교육 콘텐츠로 광고 영역을 한정.
- 실제 광고 승인이 나기 전 광고 코드나 수익 수치·가상 광고를 띄우지 않음. EEA/영국/스위스 방문자의 광고 동의 관리에는 Google 인증 CMP 및 지역별 법 검토.
- 가이드 문서 하나만으로 AdSense 승인 기대는 금물. 다양한 독창적 글과 정식 법적 안내 페이지가 더 필요하다.

## 상품 가설 (판매가 아님)
| 사용자 | 혜택 | 가격 실험 가설 |
| --- | --- | --- |
| Free | 근거 중심 분석, 다음 행동 제안, 상황별 최대 답장 1개, 사용량 상한 | 무료 |
| Plus | 답장 3안, 톤 선택 이유·장단점, 다음 대화 전략, 더 많은 분석 한도 | $9.99 대 $12.99 / 월, 모두 가설 |
| 추가 크레딧 | 기본 구독 사용량 소진 시 소량 묶음 판매 | 출시 후 필요 시 |

- Paddle에서 $9.99/월을 판매하려면 $10 미만 요율 협의 먼저 필요.
- 초기에는 Free + Plus만 테스트하고 건별 크레딧 상품은 실제 이용량이 확인될 때 추가.
- 모든 화면에서 AI가 타인의 속마음을 확정하거나 연애 성공 확률을 측정하지 않는다고 명확히 표기.
- 분석 1건 원가(입력/출력/스크린샷/재시도), 차지백, VAT, 환전, 인증/DB/고객지원까지 포함해 기여이익 계산.

## 기술 개발 로드맵
### 0. 지금 반영 완료
- plans.html — 5개 언어 Free/Plus 기획 안내; 가격 확정 전까지 결제 없음.
- guide.html — 5개 언어 원본 커뮤니케이션 교육 콘텐츠. 광고 스크립트 없음.
- 메인 페이지에서 두 페이지로 링크.
- 분석 API는 계속 무료 결과만 반환하며, 임의 유료 권한 해제 로직 없음.

### 1. 계정 및 정책 준비
- 등록 국가·세무 거주국·정산 계좌 국가 확정
- 판매자 실명/필요한 연락처/문의 경로, 정식 이용약관, 개인정보처리방침, 환불/해지 정책, 필요할 경우 일본 특정상거래법 표시
- Paddle/Sandbox 판매자 계정 개설과 도메인/개인 인증 신청
- AdSense 개인 계정 신청과 공개 가이드 콘텐츠 확장

### 2. 서버 인증/사용량/결제 테스트
- Supabase 등 인증/DB 도입: 이메일 OTP 로그인, 사용자 계정, 구독 상태, 결제 이벤트 이력, 사용량 원자적 차감
- Paddle Sandbox 구독 상품·가격 생성 및 checkout; 서버 측 고객-사용자 매핑
- Webhook raw-body와 Paddle-Signature 검증, 재전송/중복 이벤트 idempotency, 결제 상태 동기화
- Plus 권한은 로그인한 서버 세션 + DB 구독 상태로만 검사. 클라이언트의 플래그, 성공 URL, CSS blur로 권한 주지 않음
- 해지·갱신·결제 실패·환불·차지백·구독 종료 이벤트 모두 테스트
- API 비용을 막기 위한 리스크 기반 봇 제한 + 계정/IP 일일 사용량, 결제 이벤트 로깅과 데이터 삭제·보관 정책
- 정식 구매 이전까지 모든 결제 버튼 비활성화, LIVE secret 및 checkout 링크 노출 금지

### 3. 공개 출시 순서
- 결제 계정 승인과 법적 고지 확정
- 본인 소액 실거래 구매→구독 권한 즉시 반영→해지/환불 테스트
- 10~20명 제한 베타: 무료 분석 성공률, 유용성 평가, 과금 전환, 실제 AI 원가를 확인
- Plus 정식 오픈; 최소 한 달 고객지원·취소·실패 재처리 확인
- AdSense는 별도 승인과 CMP가 갖춰진 다음 공개 가이드 영역에만 도입

## 운영자 최종 확인 항목
1. 판매자 등록/실질 사업 국가: 한국/일본/기타

3. 정산을 받을 실명 은행계좌 국가: 한국/일본/기타

5. 규정상 사업을 시작할 수 있는 체류·취업 자격인지 여부 (필요한 국가에서 자체 확인)
